# Existing experience audit

Reviewed both entry files, the complete sanitized HTML/CSS/JS, event and character definitions, image overrides, map, network, quiz, search, README, launch note and repository preview before replacing the interface.

- **Structure:** index.html redirects to a 9.7 MB standalone file. Styling, content, base64 images and imperative UI rendering are coupled. There is no build pipeline, type checking or test suite.
- **Narrative:** 31 incidents cover useful material across three phases. The essential filter hides episodes needed to explain losses and transitions. Long dialogs ask beginners to read summary, narrative, interpretation, tags and a graph at once. Film cast material distracts from the ancient story. Preserve the original edition and quiz as an archive.
- **Accuracy:** useful distinctions between chronology and epic order already exist. Source references are mostly broad rather than attached to beats. The Patroclus summary incorrectly implies Hector initially mistakes him for Achilles. The underworld is a consultation of shades at Ocean's edge, not an unqualified physical descent into Hades. Helen's departure has competing traditions. The Iliad ends with Hector's funeral, not the horse. New text corrects or qualifies these points.
- **Visuals:** the collage mixes engravings and paintings, often with unrelated cropping. Repeated small dark cards compete with large text. The 19-node network keeps every edge and label visible, even when faded. Nearby labels intersect and names are abbreviated.
- **Navigation:** chronological next/previous exists inside dialogs but the main surface does not guide a complete reading. The first CTA goes to explanatory cards. No saved beat or continue offer. Some relationship buttons have no action. A map's hover feedback is inaccessible to touch and keyboard.
- **Map:** illustrative positions already have a useful disclaimer, but the land shapes are not Mediterranean geography. The route is static, with no camera or progress connection. SVG nodes are mouse-only groups.
- **Accessibility:** semantic dialogs and some labels are present. Custom SVG controls lack focus/keyboard handling; tab roles lack tab behavior. Sideways dragging and dense networks are difficult on phones. Essential text is sometimes tiny. Motion has no complete playback control.
- **Assets:** public-domain historical art remains useful for the reading edition and selected profiles. New cinematic artwork requires clear artistic-reconstruction attribution. External image overrides risk failures. Embedded images increase parse and download cost.
- **Technical direction:** replace the primary interface with React/TypeScript/Vite, structured chapters, a persisted journey store, dedicated story/atlas/character views, lazy 3D and static fallback. Keep the original file under legacy. Deliver the full readable narrative and a richer Cyclops interaction first; record remaining modeled scenes honestly.
